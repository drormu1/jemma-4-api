# Local On-Premises ChatBot Component (PoC)

רכיב צ'אט-בוט עצמאי ומבודד (Component-Based Architecture) המוטמע בתוך מערכת ליבה ארגונית המבוססת על .NET MVC ו-jQuery. 
הרכיב מיועד להטמעה מלאה ב**רשתות סגורות ומאובטחות (On-Premises / Air-Gapped Environments)**, ללא כל תלות או פנייה ישירה לאינטרנט החיצון (No CDNs, No External Fonts, No Web APIs).

---

## 📌 עקרונות ארכיטקטוניים והחלטות הנדסיות

1. **Separation of Concerns (SoC):** כל קוד הצ'אט מבודד לחלוטין מתוך דפי המערכת הקימיים ויושב תחת תיקייה אחת ייעודית: `ChatBot/`.
2. **Dynamic DOM Injection:** קובץ ה-JavaScript טוען את ה-HTML של הווידג'ט בצורה אסינכרונית (`$.get`) ומזריק אותו ל-DOM בזמן ריצה. זה מאפשר הטמעה במערכת האמיתית באמצעות שורת טעינה בודדת ב-View.
3. **No External Dependencies (Air-Gapped Ready):**
   * **אייקונים:** שימוש ב-Inline SVG בלבד. אין שימוש ב-FontAwesome או ספריות גופנים חיצוניות.
   * **פונטים:** שימוש ב-System Fonts מקומיים בלבד (`Segoe UI`, `Tahoma`).
   * **ספריות:** תאימות מלאה לכל גרסאות jQuery הקיימות בארגון (החל מ-1.7 ועד 3.x) ללא צורך בשדרוג הליבה.
4. **Data Scraping (Context-Aware):** ה-JS סורק את ה-DOM של דף ה-Index הקיים (שמות, תעודות זהות, רשימות וטבלאות דינמיות) על מנת לבנות קונטקסט עבור המענה.
5. **Plain-Text Outputs (Textarea Ready):** הבוט מחזיר תשובות בפורמט **Plain Text נקי בלבד (ללא תגיות HTML)**, תוך שימוש בירידות שורה סטנדרטיות (`\n`) ותווים מיוחדים (`*`). המטרה היא לאפשר למשתמש קצה לבצע `Ctrl+A` ו-`Ctrl+C` ולהדביק את התמליל ישירות לתוך שדות `Textarea` ארגוניים לא מעוצבים.
6. **UX דחוס ומבצעי:** רווחי העיצוב (Padding/Margin) צומצמו למינימום, וגובה הרכיב הוגדל ל-`650px` על מנת לתת מקסימום נדל"ן למסך עבור חלונית התשובה הטקסטואלית.
